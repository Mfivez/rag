# Procédure en cas de bourrage papier

## Mise en sécurité

Annuler le travail d'impression puis éteindre l'imprimante. Attendre trente secondes avant d'ouvrir le compartiment papier.

## Retirer le papier

Retirer doucement la feuille dans le sens de circulation du papier. Ne pas tirer brutalement et ne pas utiliser d'objet métallique.

## Contrôler les rouleaux

Vérifier qu'aucun morceau de papier ne reste entre les rouleaux. Refermer tous les compartiments avant de rallumer l'imprimante.

## Test

Imprimer une seule page de test. Si le bourrage revient, arrêter les essais afin de ne pas endommager les rouleaux.

## Escalade

Créer un ticket `Matériel > Impression` avec le nom de l'imprimante, son étage et le code d'erreur affiché.
